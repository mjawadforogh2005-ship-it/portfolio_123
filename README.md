# Mohammad Jawad Frogh — Professional Portfolio

A clean, modern, fully responsive single-page portfolio website.

## Features

- Dark / Light mode (remembers preference)
- Smooth scroll & active navigation
- Typed rotating titles (Front-End Developer · CS Student · English Instructor · Designer · Photographer)
- Professional timeline for experience
- Project cards with GitHub links
- Animated skill bars
- Education & certificates section
- Languages + Interests
- Contact form (demo — ready to connect to Formspree / EmailJS)
- Fully mobile-friendly

## How to use

1. Open `index.html` in any modern browser.
2. Replace the placeholder images:
   - Hero profile photo → change the `src` of `#profile-photo`
   - About section photo → change the image in `.about__img`
   - Project cover images → update the `src` inside each `.project-card__image`
3. Update personal email if needed (currently uses university email).
4. (Optional) Connect the contact form to a real service (Formspree, EmailJS, or your backend).

## Files

- `index.html` — structure & content
- `styles.css` — all styling (CSS variables for easy theming)
- `script.js` — interactivity

## Customization tips

- Colors: edit the CSS variables at the top of `styles.css`
- Fonts: currently Inter + Space Grotesk (Google Fonts)
- Add more projects by copying a `.project-card` block

Built with plain HTML, CSS & JavaScript — no frameworks required.
Ready to deploy on GitHub Pages, Netlify, Vercel, or any static host.
